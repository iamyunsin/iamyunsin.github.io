## 🚀 本地开发与构建部署

```bash
# 安装依赖
pnpm install

# 启动本地开发预览
pnpm run dev

# 生产构建（自动生成双语 Sitemap、llms.txt 并执行静态资源内容 Hash）
pnpm run build

# 手动向搜索引擎推送全站 Sitemap URL（IndexNow + 百度普通收录 API）
pnpm run seo:push
```
